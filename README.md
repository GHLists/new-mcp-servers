# New MCP Servers

Hourly lists of servers newly published to the official
[Model Context Protocol registry](https://registry.modelcontextprotocol.io/),
taken from the [registry API](https://github.com/modelcontextprotocol/registry).
A GitHub Actions workflow runs every hour, fetches the servers published since
the previous list and commits one CSV per run to [`data/`](data/), e.g.
[`data/new-mcp-servers-<timestamp>.csv`](data/).
